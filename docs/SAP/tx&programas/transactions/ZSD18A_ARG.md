description: Report for Sales Orders - Reporte de Ordenes de Venta
---
Este es el reporte de Ordenes de venta. El reporte trae un montón de campos y generalmente lo ejecuto con esta configuración. Es uno de los dos reportes que usa Tomas Alberti. 

:::tip
Para temas de integridad al bajar este reporte lo que hago generalmente es bajar todas las columnas que tiene el reporte. Esto hace que sea mas lenta la bajada pero asi despues las puedo filtrar en la base de datos
:::
